## 本地改动

正常连接时不在网页显示角标；断开或重连时显示简洁提示，可点击隐藏，连接恢复后重置隐藏状态。浏览器工具栏图标保留连接状态提示，弹窗可查看和刷新状态。去掉原 ljq_driver 文案，使用“GA 浏览器”。使用 Shadow DOM 隔离提示样式。

弹窗不再展示或自动复制 Cookie；原桥接协议及后台浏览器能力保留。页面脚本不再移除网站的 CSP meta 标签。后台初始状态改为未连接，避免启动时误报。

## 加载与更新

在 Chrome 扩展管理页面开启开发者模式，选择“加载已解压的扩展程序”，选择本目录。已有扩展应由用户自行切换到本目录，并避免同时启用两份同端口桥接插件。更新后在扩展管理页点击重新加载，并刷新已打开的网页，才能替换旧页面角标。

本机桥接地址仍为 ws://127.0.0.1:18765。该连接状态表示桥接服务可用，不代表智能体任务已经开始。此版本保留上游权限；本次未接入安装包发布流水线。

## 弹窗与桥接开关

弹窗采用连接状态、可复制的本机地址和启用桥接开关布局；更多菜单保留刷新状态和上游来源链接。开关通过 chrome.storage.local 记忆，关闭会断开 WebSocket 并停止重连，开启会重新连接。它控制桥接连接，不等同于在 Chrome 中禁用整个扩展；保留的上游内容脚本与规则不受此开关控制。新增 storage 权限仅用于保存该开关。
