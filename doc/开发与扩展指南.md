# 开发与扩展指南

普通使用者请先阅读仓库首页的[快速开始](../README.md#快速开始)。本文面向本地开发和维护。

## 项目结构

```text
checker/
├── app/          Electron + React，使用 Vite、Tailwind、Monaco
├── sidecar/      Python FastAPI 服务及 MCP 工具
├── doc/          质检流程、参考资料和开发文档
├── plugin/       可手动加载的浏览器插件
├── packaging/    安装包资源
├── scripts/      构建、包检查及辅助脚本
└── config.example.toml
```

## 本地运行

推荐使用独立 Conda 环境，在仓库根目录执行：

```bash
conda env create -f environment.yml
conda activate checker
cd app
npm install
npm run dev
```

环境创建后，也可以在 `app/` 执行 `npm run dev:conda`。

开发版 Python 选择顺序为 `CHECKER_PYTHON` 指定的绝对路径、当前非 base Conda 环境、仓库 `venv/`、仓库 `.venv/`。HTTP 服务、MCP 和脚本工具共用该解释器；打包版使用内置 Python。模型及分工表配置可通过应用设置填写。

验证命令：

```bash
# 仓库根目录
conda run -n checker python -m pytest sidecar/tests/ -q

# app/ 目录
npm test
npm run build:app
```

`build:app` 只编译前端及 Electron；`npm run build` 还会执行本机打包。更多说明见 [app/README.md](../app/README.md)。

## 会话与歌曲进度

所有会话加载完整质检手册。`start_qc` 用于歌曲名称解析与界面定位，工具参数明确指定操作目标，切歌保留会话历史。

每首歌保存一份 `state_tree/<歌曲文件夹名>/progress.md`。开发版位于 `cache/`，打包版位于应用数据目录；可通过 `CHECKER_DATA_DIR` 覆盖。进度跨会话共享；旧版平铺的进度文件读取时自动迁移，原文件保留备份。

## 公共提示词与个人扩展

公共流程位于 `doc/prompts/`，知识索引位于 `sidecar/knowledge/INDEX.md`。索引路径在启动时转换为安装位置的绝对路径，正文按需读取。客户端支持从服务器拉取已发布提示词，失败时保留上次可用版本；编辑仓库文件不会自动发布服务器版本。

`local_extensions/` 和 `local_data/` 不提交，也不进入用户安装包。开发版检测到 `local_extensions/knowledge/INDEX.md` 时加载个人知识，并提供任务提示词入口；任务提示词保存在应用 userData 下的 `current-task.txt`，留空保存可移除。

打包版默认不加载个人扩展。个人安装需要将扩展保存在包外，并通过 `CHECKER_LOCAL_EXTENSIONS` 指定根目录。包检查会拒绝个人扩展、私人任务提示词和本地配置文件，通用质检代码无需为个人版分叉。

## 高级工具

高级工具首次默认关闭，设置保存在应用数据目录的 `agent-preferences.json`。工具清单为 `code_run`、`web_scan`、`web_execute_js`、`file_read`、`file_write`、`file_patch`。

Python 使用 sidecar 解释器。临时目录在开发版为仓库 `temp/`，打包版为缓存目录下的 `temp/`，可由 `CHECKER_TEMP_DIR` 覆盖。临时脚本运行后自动清理，其他产物保留。文本写入和补丁工具仅修改该临时目录，歌曲交付文件通过 fixer 修改。Python 本身不处于操作系统沙箱中。

浏览器操作复用 GA 桥接；手动安装方式见 [插件说明](../plugin/browser-bridge/README.md)。

## 分工表与网络

服务器凭证留在服务端，客户端仅配置 HTTPS 地址及共享读取密钥。分工表内存缓存 5 分钟，过期后在下次查询时重新拉取，用户也可手动刷新。

分工表和提示词请求固定直连，使用 certifi CA 证书并拒绝重定向，不回退系统代理。TUN 等系统网络转发不在 HTTP 客户端代理设置的控制范围内。

Agent 使用 `sheet_query` 分页筛选全表，`sheet_get_song_meta` 查询单首详情。同名歌曲通过行号区分，人员姓名在工具结果中打码。筛选属于客户端行为，共享密钥并不提供按负责人隔离的服务器权限。
